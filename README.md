# ❤️ Heart Risk Analyzer

## 📌 Description
This project predicts the risk of heart disease using machine learning. It takes user input and analyzes health parameters to give prediction results.

## 🚀 Features
- User Login & Signup system
- Heart disease prediction
- Simple UI using Streamlit

## 🛠️ Tech Stack
- Python
- Streamlit
- Machine Learning
- Pandas, NumPy

## 📂 Project Structure
- app.py → Main application
- pages/ → Authentication pages
- database/ → Database connection
- .pkl files → Trained ML model
- CSV file → Dataset

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py

## 📊 Output
Predicts whether a person has heart disease or not.
